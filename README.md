# Bookshop Inventory & Affiliate Tracker

A Python automation script that reads spreadsheet data (`books.csv`) to track bookshop inventory, sales counts, and affiliate commissions—upgrading manual Excel workflows into repeatable code.

## Project Files
* **`books.csv`**: Sample inventory and sales spreadsheet (renders as an interactive table on GitHub).
* **`bookshop.py`**: Python script that reads the spreadsheet using `str`, `int`, `float`, and `bool` types to generate an earnings report.

## How to Run
```bash
python3 bookshop.py
```
